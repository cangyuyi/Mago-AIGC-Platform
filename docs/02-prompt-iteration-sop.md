# 垂类场景Prompt工业化迭代SOP
## 一、目标
建立工业化、可量化、可复现的Prompt迭代流程，将Prompt从"依赖个人经验的玄学"变成可度量、可迭代、可规模化复制的工程能力，持续提升各垂类场景的出图商用符合率，核心目标：电商/漫剧等核心场景首次出图商用符合率≥85%，用户平均重绘次数≤1.2次。

---

## 二、Prompt版本管理规范
每个垂类场景的Prompt纳入版本化管理，建立专属台账，包含以下标准化字段：
| 字段 | 规范要求 |
| :--- | :--- |
| 场景ID/名称 | 全局唯一标识，例：EC001-一键换装、COM001-漫剧分镜一致性 |
| 当前版本号 | 语义化版本号：主版本号.次版本号.修订号，例：v2.1.0 |
| 最后更新时间 | YYYY-MM-DD |
| 当前生效Prompt全文 | 包含正向提示词、负向提示词、参数要求 |
| 适配模型列表 | 该版本Prompt适配的模型清单，不同模型单独维护适配版本 |
| 测试集符合率 | 最近一次全量测试的商用符合率 |
| 历史版本记录 | 所有历史版本的Prompt全文、更新时间、优化点、测试数据、灰度效果 |
| 已知Bad Case | 当前版本未解决的问题列表，标注优先级、影响范围、根因分类 |

---

## 三、标准化迭代流程（双周迭代周期）
### 1. Bad Case全渠道收集（每日）
- 自动收集：用户点击"重绘""不满意反馈"的任务自动进入Bad Case池，关联用户输入、生成结果、模型参数、场景信息
- 客服收集：客户成功团队每日收集企业客户反馈的问题，标注客户等级、影响范围
- 主动抽样：质检团队每日随机抽取150张各场景生成结果，按照商用标准双盲标注，不符合要求的纳入Bad Case池
- 监控告警：单个场景Bad Case率连续3天超过15%自动触发优化需求，不需要等迭代周期

### 2. Bad Case量化归因（双周迭代首日）
产品+Prompt工程师+运营三方共同对周期内收集的Bad Case做量化归因，归因维度标准化：
| 问题类型 | 处理策略 | 触发阈值 |
| :--- | :--- | :--- |
| Prompt本身设计缺陷（角度错误、元素缺失、风格偏差、不符合商用规范） | 纳入本周期迭代优化 | 同类型问题占比≥10% |
| 模型能力天花板（特定模型无法实现该效果） | 更换该场景默认模型，或通过Prompt逻辑规避 | 任何影响核心体验的模型问题 |
| 用户输入不规范（信息不全、违规内容、参数错误） | 优化前端输入引导、增加输入校验提示、提供示例，不修改核心Prompt | 不影响核心用户的问题 |
| 偶发生成偏差（随机种子波动，同类型问题占比<5%） | 不做Prompt调整，优化重试逻辑引导用户重绘 | 占比<5%的偶发问题 |
> 严格控制变量：每次迭代只修改一个变量，避免多变量同时调整导致无法判断优化效果。

### 3. Prompt优化与双盲测试（迭代周中）
- Prompt工程师根据归因结果调整Prompt内容，调整后在相同模型、相同参数下运行**固定标准化测试集**（每个场景维护30组覆盖不同品类、不同需求的标准化测试用例）
- 评估标准：由2名质检人员双盲打分（不知道哪个是优化后的版本），满足两个条件才可进入灰度：
  1.  优化后版本商用符合率≥85%
  2.  相比上一版本符合率提升≥5%，且没有出现新的大面积Bad Case
- 未通过测试的版本直接废弃，重新优化，不允许带着问题上线。

### 4. 灰度发布与效果验证（迭代周五）
- 优化后的Prompt先灰度放量给10%的用户，灰度周期24小时，监控以下核心指标：
  - 该场景Bad Case率、重绘率是否下降
  - 生成成功率、用户满意度是否提升
  - 有没有出现新的异常Bad Case
- 灰度数据优于线上版本则全量发布，更新Prompt台账；数据无提升或负优化则立即回滚，下周期重新优化。

### 5. 复盘与归档
全量上线后更新版本台账，记录优化点、测试数据、灰度效果，每月复盘各场景符合率变化趋势，对连续两个迭代符合率没有提升的场景重新做深度优化。

## 四、Prompt设计规范
1.  **模块化设计**：所有场景Prompt采用模块化结构，分为「通用基础层+场景能力层+动态输入层+通用负向层」四层，通用负向词库统一维护，所有场景共享，持续迭代
2.  **模型适配原则**：一个场景针对不同模型单独维护适配版本，不追求一个Prompt适配所有模型，针对每个模型的特性做最优调优
3.  **禁止过度优化**：不为了满足单个客户的特殊需求修改通用模板，特殊需求引导用户通过自定义Prompt/专属工作流实现，避免影响大部分用户的通用效果
4.  **商用导向**：所有Prompt优化目标是"符合电商/漫剧商用标准"，不是"艺术效果最好"，优先保证出图的可用性、合规性、稳定性。

---

## 五、效果度量指标体系
| 指标 | 目标值 | 统计方式 |
| :--- | :--- | :--- |
| 核心场景首次出图商用符合率 | ≥85% | 测试集双盲标注+用户反馈抽样 |
| 用户平均重绘次数 | ≤1.2次/任务 | 后台全量统计每个任务的平均重绘次数 |
| 企业客户场景满意度 | ≥90% | 月度企业客户NPS调研 |
| Bad Case周度下降比例 | ≥3%/周 | 每周Bad Case率环比 |
| Prompt迭代负优化率 | 0 | 灰度发布后出现大面积问题需要回滚的次数 |
