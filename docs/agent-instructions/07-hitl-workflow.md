# 指令 07：人机协作与前端交互（Human-in-the-Loop & UX）

## 角色设定

你是一名**高级前端工程师+交互设计师**，擅长AI产品的Human-in-the-Loop交互设计。你理解流式输出、Copilot式辅助编辑、工作流可视化、渐进式披露等AI产品设计范式。你有复杂B端SaaS产品和创意工具（类似Notion/Figma/Runway/Midjourney/Jasper/Copy.ai）的开发经验。

## 前置依赖

必须先完成 `01-project-bootstrap.md`。本板块是**所有前端交互的集中实现**，依赖02-06板块的后端API（API可以mock先开发，联调后补）。

## 任务目标

构建一套**流畅的AI协作工作流界面**，核心原则是：
1. **用户不被AI牵着走，也不对着白纸发呆**：AI给出选项和草稿，用户有决策权
2. **过程透明**：用户能看到Agent在做什么、为什么这么做，不是黑箱
3. **修改成本低**：任何阶段都能用自然语言修改，或直接结构化编辑
4. **渐进式披露**：默认展示最关键信息，高级参数折叠给专业用户
5. **快速/精细双模式**：赶时间用"一键出片"，精品内容用逐节点审核
6. **每个节点都有"逃生舱"**：AI出的东西不满意随时可以手动改/自己写/重生成

**Chat必须支持**：

- **结构化卡片嵌入消息**：Agent不仅能回复文字，还能在消息流中直接展示：
  - 创意方向卡片（可点击选择）
  - 脚本分镜卡片（可展开编辑）
  - 提示词卡片（可复制）
  - 图片/视频预览卡片（Mago返回的结果）
  - 选择按钮（"选第1个" "选第3个" 直接点击回复，不用输入）
- **Thinking过程展示**：Agent内部的思考步骤（"正在检索爆款库..."/"找到23个相关视频"/"钩子专家正在设计3个候选"）以灰色小字/折叠面板展示，技术用户可展开，普通用户看到进度条+当前步骤即可
- **多轮上下文**：保留当前项目的完整对话历史，可回溯引用
- **编辑并重新发送**：用户可点击自己发的消息编辑后重新发送
- **重新生成**：Agent消息不满意可点击"🔄重新生成"
- **复制**：Agent消息内容一键复制
- **文件上传**：输入框支持拖拽上传参考图片/视频（粘贴也行），上传后在输入框上方显示缩略图，随消息一起发送给Agent
- **@提及资产**：在输入框中@角色/风格/场景，快速引用资产
- **停止生成**：Agent输出过程中可以点停止按钮
- **Markdown + 语法高亮**：代码块（提示词展示）用react-syntax-highlighter或shiki高亮
- **消息反馈**：每条Agent消息有👍👎按钮，反馈数据用于优化

### Step 5：创意工作台核心页面

基于板块03和04的页面结构，实现高完成度的UI。本节强调关键交互细节：

#### 5.1 灵感发散页交互
- **输入状态分三种**：
  - 空白态：一个大号输入框"想做个什么视频？"，下方有热门赛道chip（美妆/美食/剧情/知识/带货…）一键选择，"🎲随机灵感"大按钮，"🔥今日热点"入口
  - 生成中：展示骨架屏+进度（"正在搜索爆款..."/"正在跨界激发创意..."/"正在评估可行性..."）
  - 结果态：10张创意卡片2x5或1x10网格排列
- **创意卡片设计**：
  - 顶部：情绪emoji + 创意标题（大字）
  - 中部：2-3句描述+钩子方向+差异化亮点
  - 底部：标签（🔥热点关联/AI可行性/制作难度/预计时长）+ "用这个"主按钮 + "变体"次按钮 + "收藏"按钮
  - 选中状态：卡片边框高亮+收缩为已选状态
  - 多选："组合创意"模式，选2-3张卡片组合它们的优点
- **变体生成**：点"变体"按钮，该卡片变灰，旁边出现2-3张变体卡片

#### 5.2 脚本编辑页交互
- **Beat块可视化**：脚本不是一整块文字，而是按beat块拆分成卡片（钩子/开场/主体1/主体2/高潮/CTA），每个beat卡片标注功能+时长+情绪色条
- **情绪曲线图**：在脚本顶部，用recharts画情绪曲线，hover到曲线上的点高亮对应beat卡片
- **质量雷达图**：右侧常驻，6-7维度雷达，红色维度点击跳转到对应段落并给出修改建议
- **Copilot栏**：页面底部常驻输入框，随时输入自然语言修改（类似Notion AI），修改支持diff预览接受/拒绝
- **钩子候选**：钩子beat点开后默认展示3个候选钩子，可切换/编辑/自己写
- **合规警告**：有问题的段落旁出现黄色/红色警告icon，点击展开说明和一键修复按钮
- **版本时间线**：右侧有版本历史抽屉，可查看每版差异、回滚
- **节奏播放预览**（Phase 2增强）：点击"模拟播放"按钮，按每个beat的时长自动滚动，配合音频BPM节拍指示，感受节奏

#### 5.3 分镜编辑页交互
- **表格视图默认**：表格列=镜号、时长、景别、画面、台词、情绪、操作
- **内联编辑**：点击单元格直接编辑，不需要弹窗（景别/运镜是下拉选择带emoji图标）
- **拖拽排序**：拖行改变镜头顺序，镜号自动重排
- **批量编辑**：按住Shift多选多行，批量修改景别/光线/色调
- **时长条可视化**：表格上方有全局时间轴条，每个镜头按宽度占比显示长度，不同情绪用不同颜色，超出目标时长时超出部分红色警告
- **卡片展开视图**：点击镜头行展开为大卡片，展示/编辑所有字段（包含运动描述、AI备注、提示词预览）
- **AI难度指示**：每个镜头有🟢🟡🔴三级可行性标识，红色点开有简化建议
- **一键优化镜N**：展开卡片内常驻自然语言输入框，直接对该镜发出修改指令
- **缩略图占位**：分镜生成后为每个镜头预留缩略图位置，Mago生成首帧图后自动填充
- **全屏专注模式**：按F或点击全屏按钮，分镜表格全屏展示，隐藏其他UI

  - `R`：重新生成当前选中内容
  - `/`：聚焦输入框
- 全局命令面板（Cmd+K）：输入"生成脚本"/"切换到分镜"/"导出提示词"等命令快速操作

### Step 12：动画与微交互

使用framer-motion做以下动效：
- 页面切换fade-in
- 卡片出现stagger动画
- 消息出现打字效果
- 进度步骤推进
- 按钮hover/点击反馈
- 复制成功✓弹动
- 通知slide-in
- 工作流节点状态变化的平滑过渡

**原则**：动效要快（≤300ms）、克制、有目的（引导注意力/反馈操作结果），不要为动画而动画。

### Step 13：错误处理与降级体验

- 网络断开：显示离线状态条，操作暂存本地，重连后自动同步
- Agent/LLM失败：显示错误信息+重试按钮+降级选项（"LLM服务暂时繁忙，您可以手动编辑"）
- 超时：长时间任务（如视频分析）显示进度，允许后台执行（用户可离开页面，完成后通知）
- 空状态：所有列表空状态有引导（"还没有角色？→ 创建第一个角色"）
- 加载状态：骨架屏（不是转圈），保持布局稳定
