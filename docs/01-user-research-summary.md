# 用户调研摘要（150份访谈核心结论）
## 调研基本信息
- 调研时间：2026年2月（项目启动前）
- 调研样本：150名目标用户，其中个人创作者72人、电商企业运营/负责人46人、漫剧工作室从业者19人、独立设计师13人
- 调研方式：1v1深度访谈，每份访谈时长20-30分钟
- 调研目的：明确目标用户核心痛点、需求优先级、付费意愿，为产品定位和功能设计提供依据

## 三、付费意愿调研结论
1.  **价格敏感度**：个人用户能接受的生图单张成本在0.05元以内，企业用户能接受的单张成本在0.1元以内，只要比自己雇设计师/拍照便宜就愿意付费
2.  **付费决策因素优先级**：企业用户最看重「出图稳定性」>「场景匹配度」>「价格」>「模型丰富度」；个人用户最看重「价格」>「模型丰富度」>「易用性」
3.  **套餐偏好**：72%的企业用户倾向于按月充值/按用量充值，不愿意买年卡；个人用户倾向于小额充值，先试再买
4.  **复购驱动因素**：企业用户复购的核心原因是「出图稳定，不用自己折腾」，如果一个月内出现2次以上大面积生成失败，大概率会流失

## 四、需求优先级决策（MoSCoW）
基于调研结论确定v1.0-v1.3版本的需求优先级：
### Must have（必须做）
- 海外主流模型接入，国内直连无需翻墙
- 基础文生图/对话能力
- 基础计费系统，按用量扣积分
- 基础错误重试机制
### Should have（应该做）
- 电商场景核心Prompt模板（白底图、套图、换装）
- 多API渠道调度，保证稳定性
- 历史记录和素材管理
### Could have（可以做）
- 节点式工作流画布
- 生视频能力
- 更多场景模板
### Won't have（暂时不做）
- 本地部署选项
- 社区功能（作品分享/评论）
- 模型微调训练功能（投入产出比低，初期不做）
