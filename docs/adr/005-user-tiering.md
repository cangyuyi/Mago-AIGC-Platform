# ADR-005: B端优先的商业化路线与用户分层策略决策
**状态**：生产环境执行中，验证PMF **生效日期**：2026-02-25 **决策者**：核心团队联合商业评审
---

## 背景
项目启动阶段需要确定核心目标客群和商业化路线：是做C端通用流量靠广告/会员变现，还是聚焦B端垂直企业客户靠SaaS订阅/按量付费变现，不同路线的产品架构、资源投入、增长方式完全不同，需要基于单位经济模型和竞争格局做战略决策。

## 可选路线评估
### 路线1：C端流量优先路线，主打DAU规模
- 实现方式：主打免费/低价C端用户体验，靠社交媒体传播做大规模DAU，后续通过广告、会员增值变现
- 优势：增长速度快，容易做出亮眼的用户规模数据，市场传播声量大
- 劣势：
  - 单位经济模型极差：C端用户ARPU值极低（国内AIGC C端用户月均ARPU<10元），而AIGC算力是可变成本，DAU越高亏损越多，C端免费模式本质是靠融资补贴烧钱，没有正向现金流的可能
  - 竞争格局极差：互联网大厂（字节、百度、阿里）都在投入资源做C端免费AIGC工具，流量、资金、品牌都有碾压性优势，创业公司不可能在通用C端市场打赢大厂
  - 用户留存极低：C端用户迁移成本为零，哪个平台免费就去哪里，没有任何忠诚度，无法构建长期壁垒
  - 算力成本不可控：C端流量波动大，热点事件带来的突发流量会导致算力成本瞬间飙升，很容易出现亏损失控
### 路线2：中小B端垂直客户优先路线，聚焦有明确付费意愿的高价值场景
- 实现方式：聚焦跨境电商、漫剧制作等有明确内容生产需求、付费能力强、付费意愿明确的垂直行业客户，靠生产效率提升的价值收费，做深场景SaaS能力
- 优势：
  - 单位经济模型健康：企业客户ARPU值高（月均ARPU>1000元），付费意愿强，算力成本占客单价比例<30%，有健康的毛利空间，可实现正向现金流
  - 竞争格局好：大厂聚焦通用C端市场，不会深度投入垂直细分行业的场景化能力，创业公司在垂直场景的行业理解、响应速度、定制化能力上有差异化优势
  - 留存率高、壁垒深：企业客户将生产流程迁移到平台后，有很高的迁移成本，续费率稳定，随着客户使用深度增加，LTV持续提升
  - 需求清晰迭代效率高：企业客户会明确提出需求，不需要猜测用户痛点，产品迭代目标明确，可快速打磨产品能力
- 劣势：增长速度相对平缓，不会出现爆发式病毒增长，需要深耕行业积累客户
### 路线3：C端免费引流+B端变现的混合路线
- 实现方式：C端免费获取流量，从中筛选转化B端付费客户
- 劣势：初期资源有限，同时兼顾C端体验和B端场景能力会导致资源分散，两边都做不好；C端免费用户会消耗大量算力成本，且高峰时段会抢占B端客户的算力资源，影响付费客户体验，得不偿失

## 决策结果
**v1阶段坚定选择路线2：中小B端垂直客户优先，聚焦电商/漫剧两个核心垂直场景，所有资源围绕企业客户的生产需求打磨，C端用户仅做自然口碑补充，不投入任何资源做C端流量增长，优先保证付费企业客户的体验和SLA。**

## 决策权衡核心依据
1.  **单位经济模型是商业本质**：AIGC是可变成本模型，每生成一张图都有明确的算力成本，C端模式的ARPU覆盖不了成本，本质是靠融资补贴的不可持续模式；B端模式有健康的毛利空间，可实现自我造血，是长期可持续的商业模式。
2.  **差异化竞争原则**：不和大厂在通用C端市场正面竞争，聚焦大厂看不上、做不深的垂直细分场景，构建场景know-how壁垒，是创业公司的最优生存策略。
3.  **资源聚焦原则**：初期资源有限，必须集中所有资源打磨核心客群的核心体验，分散资源做C端会导致B端体验做不好，最终两边的用户都留不住。
4.  **LTV/CAC效率优先**：B端客户虽然获客速度慢，但LTV/CAC比值远高于C端客户（B端LTV/CAC可达7以上，C端普遍<1.5），长期资本回报率更高。

## 落地效果验证
1.  上线6个月验证PMF，企业客户贡献100%营收，综合毛利率25%+，连续正向盈利，没有烧钱
2.  企业客户月复购率稳定在75%+，LTV/CAC>7，远高于SaaS行业3的合格线，现金流健康
3.  聚焦电商场景打磨的7类生产模板成为核心竞争力，企业客户主动转介绍率超过30%
4.  虽然没有投入资源做C端推广，靠自然流量积累的个人用户也贡献了不错的口碑，没有额外成本。
