# ADR-004: v1阶段不做基础模型自研/微调的战略决策
**状态**：v1阶段执行中，v2阶段重新评估 **生效日期**：2026-02-20 **决策者**：核心团队联合战略评审
---

## 背景
项目启动阶段，大量AIGC创业公司都在宣传"自研垂类大模型""专属微调模型"，团队内部也评估了v1阶段投入资源做基础模型微调的可行性，需要从战略层面确定长期技术路线：是做模型层研发，还是聚焦应用层构建产品和工程壁垒。

## 可选路线评估
### 路线1：v1阶段就投入资源做垂类基础模型微调
- 实现方式：采购GPU算力集群，标注电商/漫剧垂类数据集，基于开源基础模型做全参数微调或LoRA微调，打造"专属垂类模型"
- 优势：对外宣传有"自研模型"的故事性，理论上垂类场景效果可以做到针对性优化
- 风险与劣势：
  - 投入成本极高：单A100集群年投入数十万，需要专职算法团队，固定成本极高，对现金流压力极大
  - 迭代速度劣势：基础模型行业迭代速度极快，头部厂商每1-2个月就会发布新一代基础模型，能力提升幅度巨大，垂类微调模型很容易在3-6个月内被新的通用基础模型超越，前期投入容易打水漂
  - 能力天花板低：小团队在基础模型上的投入规模和头部厂商有数量级差距，微调后的模型在通用能力、泛化性上永远不可能超过头部厂商的基础模型
  - 机会成本极高：投入核心资源做模型研发，会挤占产品体验、稳定性、场景落地的资源，而后者才是企业客户真正愿意付费的价值
### 路线2：聚焦应用层能力，不做基础模型微调，核心投入多模型调度、场景工程能力
- 实现方式：不碰基础模型训练，第一时间接入全球最新的主流基础模型，核心资源投入到"多模型智能调度、垂类Prompt工程体系、企业级稳定性、场景化工作流"等应用层能力，用工程和产品能力构建壁垒
- 优势：
  - 投入产出比高：相同的资源投入到应用层，可以直接提升用户体验、降低成本、提升稳定性，用户可感知价值明确
  - 迭代速度快：头部厂商发布新模型后24小时内即可完成接入，始终让用户用到全球最强的模型能力，不会被技术迭代淘汰
  - 现金流健康：不需要持续投入高额GPU和算法成本，可快速实现正向现金流，自我造血滚动发展
  - 壁垒更坚实：应用层的场景know-how、工程稳定性、客户服务能力是基础模型厂商不会做、也做不深的领域，不会因为模型迭代而消失
- 劣势：对外宣传没有"自研大模型"的故事性，听起来不够"硬核"
### 路线3：轻量LoRA微调覆盖特定场景
- 实现方式：不做全参数微调，仅针对极个别细分场景训练轻量LoRA插件
- 优势：成本比全参数微调低
- 劣势：LoRA能力提升有限，面对新一代基础模型优势快速消失，投入产出比依然不高，且仍然需要算法人力投入，分散资源

## 决策结果
**v1阶段坚定选择路线2：聚焦应用层核心能力建设，不投入资源做基础模型自研/微调，所有资源倾斜到调度、场景、稳定性、体验上，为客户提供"最新模型+最优体验+最高性价比+最稳服务"的应用层价值；v2阶段当企业客户有明确付费定制需求时，再针对特定大客户的专属场景做轻量定制化微调。**

## 战略决策核心依据
这是项目最重要的顶层战略决策，核心认知：
1.  **产业分工认知**：大模型行业有明确的产业分工，基础模型研发是头部厂商的军备竞赛（百亿级投入），应用层团队的核心价值不是重复造轮子做模型，而是把全球最好的模型能力以最低的成本、最稳定的服务、最贴合场景的方式交付给客户，这才是应用层创业公司的核心价值。
2.  **壁垒认知**：AIGC应用层的核心壁垒从来不是模型本身（模型永远会越来越便宜、能力越来越强），而是对垂直行业场景的深度理解、工程化稳定性能力、成本管控能力、客户服务能力，这些能力不会因为新模型发布而消失，反而会随着客户积累越来越深。
3.  **客户价值认知**：企业客户真正付费的点不是"你有没有自研模型"，而是"能不能稳定生成符合要求的图、能不能提升生产效率、能不能比自己雇人便宜"，为了"自研模型"的故事投入成本，最终要么涨价让客户买单，要么牺牲体验，都是本末倒置。
4.  **生存优先原则**：ToB SaaS公司首先要实现自我造血，靠客户付费活下来，而不是靠烧钱讲故事，聚焦应用层能力6个月即可跑通正向现金流，做模型研发需要持续烧钱，不确定性极高。

## 落地效果验证
1.  上线6个月实现连续正向盈利，毛利率稳定25%+，没有外部融资依赖，同期大量投入做自研模型的AIGC创业公司因为现金流断裂倒闭
2.  GPT-Image、Midjourney v6、Sora等新一代模型发布后，我们24小时内即可完成接入，用户第一时间用到全球最强的能力，比同期做自有微调模型的平台能力领先3-6个月
3.  所有资源投入到客户可感知的体验和稳定性上，平台可用性达到99.9%，电商场景出图符合率达到87%，获得20+企业客户的付费认可
4.  目前已经有多家大客户提出专属场景微调的付费需求，v2阶段将基于明确的客户付费需求投入定制化微调，投入产出比可量化，不会做无意义的技术炫技。
